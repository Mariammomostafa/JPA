# Java JPA project
- It's maven project using JPA to apply Data base operations
- create JPA xml file  under src/main/resources/META-INF 
- Write all DataBase connection info inside persistence-unit of JPA xml file 
- create EntityManagerFactory obj based on specific persistence-unit of xml file
- create EntityManager from EntityManagerFactory obj
- use EntityManager obj to apply CRUD operations


### Prerequisites
- Java 8
- hibernate-core 6.0.0.Final
- mysql-connector-j 8.3.0
- IDE (Eclips)
